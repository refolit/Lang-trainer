## 1. Задача (ТЗ)

**Продукт:** мобильное PWA-приложение для изучения китайского языка с нуля, для русскоязычного пользователя.

**Формат:** один HTML-файл (single-file PWA), работает на телефоне (iOS/Android) из браузера или как приложение с экрана «Домой» (standalone). Без сервера, всё хранится локально в браузере.

**Ключевые требования:**
- Словарь карточек: иероглиф / слово / предложение, пиньинь, перевод, метка-группа.
- Режим «Учить» — карточки с озвучкой (встроенный синтез zh-CN + свои MP3), SRS-интервалы (ящики Лейтнера).
- Режим «Письмо» — тренировка начертания иероглифов по контуру и по памяти (через HanziWriter).
- Режим «Экзамен» — узнавание перевода + письмо, с результатом и списком ошибок.
- Статистика: выучено/изучаю/дней подряд, календарь активности.
- Дизайн в духе uHabits (минимализм, статистика) и Quizlet (геймификация, «физические» кнопки).

## 2. Технический стек

| Компонент | Решение |
|---|---|
| Файл | `hanzi-trainer/index.html` (единственный источник правды) |
| Офлайн-сборка | `hanzi-trainer/hanzi-trainer-offline <цифра версии>.html` (генерируется скриптом) |
| Сборщик | `hanzi-trainer/build-offline.mjs` (Node, вшивает библиотеки и данные иероглифов) |
| Написание иероглифов | HanziWriter 3.6 + hanzi-writer-data (58 иероглифов вшито в офлайн) |
| Пиньинь | pinyin-pro 3.29.4 (UMD global `pinyinPro`) |
| Озвучка | Web Speech API (`speechSynthesis`, zh-CN) + свои MP3 |
| Хранилище | IndexedDB: `hanzi-trainer`/store `kv` (ключи `items`,`settings`,`stats`,`aud:…`); `hw-char-data`/store `c` |
| SRS | Ящики Лейтнера `LEITNER=[0,1,2,4,7,14]` дней (box 0–5) |
| PWA | `sw.js` (service worker, только на https/localhost) |

**Структура карточки (item):**
`id, kind(char|word|sentence), hanzi, pinyin, translation, tag, starred, note, recordings[{speed,name,url}], box, nextDue, correct, wrong, correctStreak, correctStreakDays, lastCorrectDay, learnedOn, addedOn`

**stats:** `{ streak, lastDay, activity: { 'YYYY-MM-DD': count } }`

## 3. Правки — первая партия (9 шт.)

1. **Остановка звука при переключении между режимами** — при уходе с экрана «Учить» озвучка не продолжает играть.
2. **Перемешивание в «Учить»** — очередь слов строится случайно.
3. **Пиньинь и перевод сразу** — на карточке видны сразу, не после ответа.
4. **Переключатель скорости** — 🐢 медленно / 🔊 всё подряд / 🚶 обычно / ⚡ быстро (задаёт, какую запись проигрывать).
5. **В экзамене — обычная скорость** — независимо от выбранной скорости изучения.
6. **Экран результатов экзамена** — счёт, проценты, кнопки «Пройти ещё раз» / «Повторить слова», список ошибок.
7. **Увеличены шрифты** — крупнее иероглиф/пиньинь/перевод.
8. **Подсветка иероглифа** — текущий иероглиф слова подсвечивается в полосе символов.
9. **Раздельные размеры шрифтов** — настройки отдельно для иероглифа, пиньиня, перевода (`mulH/mulP/mulT`).

## 4. Правки — вторая партия (10 шт.)

1. **Режим «Учить»**: `Ещё раз` → **«🔄 Повторить»** (проиграть звук заново, `studyRepeat()`); `Знаю` → **«➡️ Следующее ✓»** (следующее случайное слово, `studyNext()`). Иероглиф не настолько крупный, чтобы скрывать перевод.
2. **Режим «Письмо»**: окно по центру, рассчитано на 1–3 иероглифа; кнопки по углам.
3. **Кнопки письма**: 🔊 озвучка — слева сверху, ✨ Анимация — слева сверху, «Дальше ▸» — справа сверху.
4. **Контур виден сразу**: иероглиф показывается контуром (`writer.showOutline()`), при правильном написании моргает и снова показывает контур; счётчик повторов 1–5.
5. **Последовательность**: иероглифы слова/предложения пишутся по порядку; после завершения слова — случайное слово из списка (`nextWriteFromList()`).
6. **Звёзды** ⭐: поле `starred`, чекбокс в карточке, звёздные слова идут первыми во всех режимах (`buildStudyQueue()`).
7. **«Выучено» только после 10 дней подряд** правильных ответов в экзамене: `markExamCorrect()` инкрементит `correctStreakDays` по дням; при 10 — `learnedOn=сегодня`, `box=5`. Промах (`markExamWrong()`) полностью сбрасывает `correctStreakDays`.
8. **Статистика** (экран «Ещё»): карточки «всего / добавлено сегодня / выучено / изучаю» + календарь активности за 70 дней (`stCal`) + серия дней.
9. **Дизайн uHabits**: pill-навигация, карточки с мягкой тенью, числа в чипах заголовка.
10. **Геймификация Quizlet**: кнопки с «3D»-поджатием — тень `0 4px 0` + сдвиг вниз при нажатии (`:active { transform: translateY(...) }`).

## 6. Правки — третья партия (переработка «Письмо» + «Словарь»)

### 6.1 Режим «Письмо» — переработан полностью

- **Верхняя панель по центру** над окном рисования: кнопки 🔊 Аудио · ✨ Анимация · ◌ Контур · ◀ Назад · ▶ Вперёд. Назад/Вперёд визуально чуть крупнее (класс `lg`).
- **Под панелью** — текущее слово/предложение целиком, текущий иероглиф подсвечен классом `cur`.
- **Под окном рисования** — пиньинь текущего иероглифа (`#writePy`), ещё ниже — перевод слова/предложения (`#writeTr`), некрупным шрифтом.
- **🔊 Аудио**: по умолчанию ВКЛ (`settings.writeAudio`). Каждый новый иероглиф озвучивается (`speak(ch, 0.7)`). Выкл — тишина.
- **✨ Анимация**: по умолчанию ВЫКЛ (`settings.writeAnim`). Клик — проигрывает порядок черт один раз, НЕ сбрасывается автоматически. Для предложения играет последовательно все иероглифы по порядку. Повторный клик во время анимации — немедленно выключает её (токен `writeToken`).
- **◌ Контур**: аналог «Show outline» у hanziwriter.org. По умолчанию ВКЛ (`settings.writeOutline`). Переключается в любой момент, состояние сохраняется до смены пользователем.
- **Запуск режима**: Анимация — выкл, Контур — вкл (или последнее сохранённое), Аудио — вкл. Показывается самое недавно добавленное слово/предложение (добавленное сегодня — первым, иначе вчерашнее, по убыванию даты). Рисовать можно сразу.
- **После верного написания**: иероглиф мигает (`blinkWriteArea`) → тот же иероглиф показывается снова для переписывания. Настройки не сбрасываются.
- **Цикл по иероглифам**: все символы показаны над окном, текущий подсвечен; после последнего снова первый — бесконечный цикл до выхода из режима.
- **Назад/Вперёд**: мгновенно переключают на соседний иероглиф (даже незавершённый), состояния кнопок не меняются, пиньинь и перевод обновляются.
- **Убрано**: счётчик повторов, кнопка «Готово» и любые подтверждения — только мигание и автопереход.

**Ключевые функции:** `loadWritePrefs() / applyWriteToggles() / writableItems() / startWrite() / setWriteItem() / writeGoto() / writePrev() / writeNext() / stopWriteAnim() / startWriteChar() / startWriteQuiz() / onCharComplete() / blinkWriteArea() / toggleWriteAudio() / toggleWriteOutline() / toggleWriteAnim() / playWriteAnim()`.

### 6.2 Режим «Словарь» — переработан

- **Список по центру**, не на всю ширину (`max-width:560px; margin:0 auto`), как на quizlet.com.
- **Карточка слова** = 3 колонки: иероглиф · пиньинь · перевод. Справа сверху: кнопки ★ (звезда), 🔊, ✎ (редактирование) + статистика «Повторялось N раз.».
- **Кнопка ★**: переключает цвет (`starred`), даёт слову приоритет — оно идёт в начале в «Учить»/«Письмо»/«Экзамен».
- **Переключатель «Все слова / ★ Слова с *»** в настройках словаря (`#dictFilterSeg`). По умолчанию «Все слова». Звёздные — с приоритетом, но внутри них всегда работает перемешивание.
- **🔊 в карточке**: озвучка слова/предложения на обычной скорости (`playWordNorm()`).
- **✎**: открывает карточку на редактирование.
- **Автоперевод**: ссылка «Яндекс.Перевод» справа сверху над полем перевода — открывает translate.yandex.ru (`source_lang=zh, target_lang=ru`); если Яндекс недоступен — фолбэк на любой другой переводчик, ссылка переименовывается в «Перевести». После вставки перевода ручная правка остаётся возможной.
- **Автопиньинь**: при вводе китайского слова/предложения пиньинь подставляется автоматически (`fHanzi.oninput`), кнопка «Подставить сам» удалена.
- **Экзамен с приоритетом звёзд**: `examItems = shuffle(starred).concat(shuffle(остальные))`.

**Ключевые функции:** `dictStarFilter / dictFiltered() / toggleStar(id) / renderDict() / playWordNorm() / autoTranslate()` (с `trFallback`).

## 6.3 Правки — четвёртая партия (5 шт.)

1. **«Учить» — исправлено зависание «Следующего»** — `studyNext()` раньше обновлял карточку внутри `persist().then(...)`, и асинхронная запись в IndexedDB тормозила UI. Теперь индекс продвигается синхронно (`studyIdx++; showStudyCard(); updateChips();`), а `persist()` вызывается после (fire-and-forget). Добавлена кнопка **«◀ Назад»** (`studyBack()`) — предыдущее слово/предложение, с ограничением на индексе 0.

2. **«Письмо» — список слов внизу, только на китайском** — после блока с переводом добавлен `#writeList`: все слова из словаря китайскими иероглифами, простым списком слева направо (`flex-wrap`). Звёздные идут в начале. Клик по слову загружает его в окно рисования (`setWriteItem`). Текущее слово подсвечено классом `cur`. Кнопки Назад/Вперёд в верхней панели тоже ходят по этому списку.

3. **«Письмо» — кнопка «Рандом»** — в настройках (Ещё) добавлен сегмент `#writeOrderSeg` «Письмо: порядок слов» (Обычный / Рандом, ключ `settings.writeOrder='seq'|'rand'`). При «Рандом» слова в письме идут в случайном порядке; звёздные по-прежнему первыми, но внутри них тоже работает перемешивание (`shuffle(star)` + `shuffle(rest)`). При «Обычный» — порядок по дате добавления (свежие первыми).

4. **«Письмо» — центрирование иероглифа** — `#writeArea` стал flex-контейнером с `align-items/justify-content:center`, svg по центру окна (`margin:auto`).

5. **«Письмо» — кнопка «Подсказка»** — в настройках добавлен сегмент `#writeHintSeg` «Письмо: подсказка» (Вкл/Выкл, ключ `settings.writeHint='on'|'off'`, по умолчанию ВКЛ). Вкл — над окном рисования показывается текущее слово/предложение с подсветкой иероглифа (`renderWriteWord()`). Выкл — блок скрывается и пустеет. Параметр не сбрасывается и не включается автоматически ни в каком режиме — только вручную.

**Ключевые функции:** `studyNext()/studyBack()`, `writeWordList()/rebuildWriteSeq()`, `writePrev()/writeNext()`, `renderWriteList()`, `writeRandOn()`, `writeHintOn()/onWriteHintChange()`, `onWriteOrderChange()`, `startWriteChar(quiet)` (создание HanziWriter с опцией `showOutline:writeOutlineOn`).

**Важный технический вывод по Контуру:** рантайм-методы `writer.showOutline()/hideOutline()` ненадёжны (меняют `_options.showOutline`, но слой в DOM не перерисовывается). Надёжный способ — передавать `showOutline` в опциях `HanziWriter.create()` и пересоздавать вьюер при переключении: `toggleWriteOutline()` вызывает `startWriteChar(true)`. Поэтому контур теперь гарантированно остаётся выключенным при переходе к следующему слову.

## 6.4 Правки — пятая партия (аудио + сетка + порядок + Экзамен)

1. **Аудио в обычном темпе во всех режимах** — карта скоростей `{slow:0.55, norm:1, fast:1.18}`; нормальная скорость = 1.0. Произношение в «Письмо» и «Экзамен» — **слово/предложение целиком** (например, 父母 проговаривается как fùmǔ, а не по иероглифам): `playWordNorm()` и локальный `speak()` получают полный `it.hanzi`.

2. **Окно рисования иероглифов** — во всех режимах окно стоит строго по центру (`#writeArea` и `#examWriteArea` — flex-центрирование). Внутри — направляющая клетка по образцу китайской прописи: синяя пунктирная внешняя рамка, тонкие пунктирные средняя линия и диагонали, **серые точки** 3×3 (по 8-дольной сетке, `step = N/8`). Реализовано SVG-оверлеем `.hz-grid` (`makeGuideSVG()` / `attachGuide()`), у иероглифа — fallback `.hz-fallback`; пиксельный вариант ставится как второй слой.

3. **«Учить» — порядок слов** — `buildStudyQueue()`: сначала свежедобавленные слова (`correct==0 && wrong==0`, без звёзд), затем звёздные, затем остальные; каждая группа в случайном порядке.

4. **«Экзамен» — полная переработка**:
   - **Панель настроек** (`#scr-exam` сверху): кнопки «Верно-неверно», «Выбор ответов», сегмент «4-6-8-10» (по умолчанию 8), «Письменно», «Подбор». По умолчанию включены все, кроме «Подбор». Ключи: `settings.examTf / examChoice / examChoiceN / examWrite / examMatch`. Всегда остаётся включённым хотя бы один режим (guard в переключателе).
   - **Расположение** (сверху вниз): настройки режима → перевод → пиньинь → полное слово/предложение → окно рисования.
   - **Верно-неверно** (`renderExamTF`): показывается иероглиф + перевод (с вероятностью 50% перевод верный или чужой), кнопки «Верно»/«Не верно»; ошибка — мигание `badShake`.
   - **Выбор ответов** (`renderExamChoice`): иероглиф + 8 кнопок-переводов (число по сегменту 4-6-8-10); ошибка — мигание и снижение рейтинга слова.
   - **Письменно** (`renderExamWrite`): без подсказки иероглифа (только перевод + пиньинь + точки-маска), кнопки «Стереть»/«Готово» убраны, одна кнопка **«Вперёд ▶»** — пропуск без оценки. Автопереход к следующему иероглифу/заданию после завершения написания (quiz `onComplete`).
   - **Логика** (`examBuildSeq`): для каждого слова с переводами строится последовательность задач (write — по одной на иероглиф, choice — одна, tf — одна), звёздные первыми; внутри группы — перемешивание + разбивка трёх подряд одинаковых режимов. Каждая задача выбирает случайный режим из включённых; слово выбирается случайно.
   - **Подбор** (`matchStart/matchNextRound/renderMatch`): кнопка «Подбор»; два столбца — иероглифы слева, перемешанные переводы справа; правильная пара — затухает `.done`, ошибка — мигание; 5 пар за раунд, после завершения — автоматически новый раунд из 5 пар; звёздные первыми; кнопка «Завершить» возвращает в обычный экзамен (`examReturnToExam`).

## 6.7 Правки — восьмая партия (SRS: 5 коробок + «новое слово» 3+3)

1. **«Новое слово» (условие 3+3)** — слово считается новым и одновременно находится в коробке 1, пока не выполнит: **3 верных ответа подряд в одной сессии**, затем **3 верных подряд в следующей сессии** (в обоих случаях между показами были другие слова). Считается **только** подрежим «Выбор ответов»; счётчик **общий** для «Письма» (верные написания) и «Экзамена» (верные ответы в «Выборе ответов»). Выполнив 3+3 — слово перестаёт быть новым и покидает коробку 1 (→ коробка 2, `dueSess=+4`). Правило «между показами были другие слова» — через глобальный `SHOW_N` и поле `nsLastGoodShow` (`lastShowN − nsLastGoodShow > 1`). Если во второй сессии набрано <3 верных — вторая тройка сбрасывается целиком (`sweepNewStage` на входе в сессию: окно «следующая сессия» прошло без трёх верных → сброс).

2. **Приоритет новых слов** — новые показываются раньше старых в «Учить», «Письмо» и «Экзамене» (`queueStudy`).

3. **Чередование 2:1** — 2 новых на 1 старое в тех же трёх режимах; если новых больше, чем позволяет пропорция (10 новых / 1 старое) — после последнего старого идут новые подряд; если новых нет — цикл старых (`queueStudy`).

4. **Звёздочка** — повышенный приоритет в «Учить», «Письмо» и «Экзамене» (`studyPool`: звёздные сверху, внутри каждой группы — «давно не видел — первым»).

5. **5 коробок, интервалы в сессиях** — `BOX_INT=[0,1,2,4,6,8]` (коробка 1→1, 2→2, 3→4, 4→6, 5→8 сессий). Верный ответ/написание → следующая коробка; ошибка → **откат на 2 коробки** (5→3, 4→2, 3→1, 2→1) и повтор в текущей сессии. Коробка 5 — конечная (слово всплывает раз в 8 сессий, при ошибке падает в коробку 3). `dueSess` — сессия следующего показа; если время ещё не пришло — коробка не двигается.

6. **Очередь** — «давно не видел — первым» (сортировка по `lastSeen`); когда новые слова заканчиваются — очередь зацикливается («Учить» — `resetStudyQueue`, «Письмо» — `rebuildWriteSeq`); когда старые заканчиваются — новые идут подряд.

7. **Подрежимы «Экзамена»** — «Письменно» и кнопка «Контур» **убраны**. Остались «Верно-неверно», «Выбор ответов» (4/6/8/10) и «Подбор». В условие 3+3 считаются ответы **только** «Выбора ответов» (при любом числе карточек) и верные написания «Письма». ВН и Подбор двигают коробку (`srsGoodSoft`/`srsBadSoft`), но **не трогают** счётчик 3+3.

**Ключевые функции:** `SESS / SHOW_N / enterSession / sweepNewStage / migrateItem / srsGood / srsGoodSoft / srsBad / srsBadSoft / demoteBox / newGood / isDue / isNewWord / studyPool / queueStudy / examCorrect / examMistake / examCorrectCounted / examMistakeSoft`.

**Миграция:** `migrateItem` (флаг `__v3`) переводит старую карточку Leitner (`box` 0..5) в коробки 1..5: `newDone=(box>=1 || learnedOn)`, `box` зажимается в 1..5, `dueSess=0`, заводятся поля счётчика 3+3.

## 6.10 Правки — одиннадцатая партия (смена слова при каждом задании + единое моргание ошибки)

**Экзамен — смена слова:**
1. **При каждом новом задании выбирается новое слово** по стратегии порядка повторения. Одно и то же слово **не показывается дважды подряд** — ни внутри подрежима, ни при переходе между подрежимами.
2. **Отступ «минимум 5 других заданий»** — слово не возвращается, пока не прошло 5 других заданий. Это фильтр поверх стратегии: если слово подходит по приоритету раньше — оно пропускается, берётся следующее. После 5 заданий слово снова доступно по общей стратегии.
3. **Если слов меньше 5** — отступ действует «по возможности»: сначала исключаются недавние повторы, затем берётся слово, которое «отдыхало» дольше всех. (`examBuildSeq` переписан: линейный проход по пулу, подрежимы чередуются `choice → tf → choice → …`, каждое слово за проход — по одному заданию на включённый подрежим; выбор по «самому давнему показу» с жёстким порогом `EXAM_MIN_GAP=5`.)
4. **Повтор после ошибки** — слово больше не вставляется сразу после текущего задания: `requeueExam` кладёт его **в конец** очереди, чтобы между показами прошли другие задания (согласовано с правилом «без дублей подряд»).

**Экзамен — моргание:**
5. **Единое моргание при неверном ответе во всех подрежимах** — выбранная карточка (или кнопка) быстро мигает (`@keyframes badBlink`, 0.45 s: opacity 1→0.3 с усилением яркости).   - Баг по дороге: `window.supabase` оказался объектом (а не функцией) — проверка `sbReady()` исправлена на `typeof window.supabase.createClient==='function'`.

**Не сделано / возможные следующие шаги** (дальше по [SYNC_PLAN.md](SYNC_PLAN.md)):
- Пользователю: проверить реальный вход по ссылке из письма на GitHub Pages (Фаза 3, пункт «Проверка входа»).
- Фаза 4 — кнопка «Синхронизировать» + LWW-слияние по `updated_at`.
- Фазы 5–8 — мультиязычность, аудио в Storage, каталог, полировка/I18N.
- Публикация свежего офлайн-файла по live-ссылке (Cloudflare quick tunnel) — не выполнена, предложена.

## 8. Как пересобрать офлайн-версию

```bash
node /tmp/build-offline.mjs "D:/! MyProjects/Claude original/hanzi-trainer"
```

Скрипт читает `index.html`, скачивает HanziWriter + pinyin-pro + данные 58 иероглифов и пишет `hanzi-trainer-offline <цифра версии>.html` (берёт последнюю цифру из `APP_VERSION`). Внешние `<script>` заменяются вшитыми, фолбэки убираются.

**Проверка после сборки:**
- В офлайн-файле не должно быть `<script src="https://cdn...` (внутри библиотеки hanzi-writer остаются текстовые упоминания `cdn.jsdelivr.net` — это не скрипты, а дефолтный загрузчик данных; приложение их не использует).
- `window.__BUILTIN_CHAR_DATA__` содержит 58 ключей.

## 9. Важные нюансы для пользователя

- **MP3-аудио копируется в IndexedDB** (ключ `aud:<id>:<speed>`), оригинал файла после загрузки не нужен. Но очистка данных сайта/браузера стирает аудио.
- **Чтобы увидеть свежую версию на телефоне** после правок: пересоздать ярлык PWA или очистить данные сайта — иначе старый service worker отдаёт закэшированный `index.html`.
- **Бэкап** — кнопка «Экспорт JSON» (в неё входят и аудио в base64); «Импорт JSON» восстанавливает.
